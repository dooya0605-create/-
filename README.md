# 턱없이 — 마산합포구 접근성 길찾기 시연

마산합포구를 실제 지도 배경으로 보여주고, 경사·계단·좁은 보도·문턱을 피하는 접근성 경로 탐색 콘셉트를 시연하는 웹 프로토타입입니다.

## 실행

- Node.js 20.6 이상 설치
- `npm install`
- `.env.example`을 `.env`로 복사
- `npm start`
- `http://localhost:3000` 접속

지도는 MapLibre GL JS와 OpenFreeMap의 공개 Liberty 스타일을 사용합니다. 지도 표시에 API 키는 필요하지 않습니다. 인터넷 연결이 필요하며 외부 지도 서비스의 일시 장애 가능성은 있습니다. 지도 저작자 표시는 지도에 제공되는 컨트롤을 통해 표시됩니다.

## 이 화면이 시연하는 것

- 실제 마산합포구 지도 배경
- 출발지·도착지 입력 화면과 지도에서 위치 지정 UI
- 접근성 우선 경로와 최단 거리 경로의 시각적 비교
- 급경사·계단·좁은 보도·문턱 회피라는 제품 콘셉트
- 접근성 우선 경로 강조와 모바일 레이아웃

## 시연 범위와 주의사항

이 버전은 발표용 UI 시연입니다. 화면에는 분명히 시연용이라고 표시하며, 입력 텍스트를 실제 지오코딩하지 않고 경로·거리·시간·장애물 정보도 실측하거나 계산하지 않습니다. 경로 선과 위험 지점은 제품의 기능 방향을 보여주기 위한 예시 오버레이이며 실제 도로 경로가 아닙니다. 따라서 실제 이동이나 안전 판단에 사용하면 안 됩니다.

실서비스를 만들려면 장소 검색/좌표 변환, 보행 도로 네트워크 길찾기, 급경사·계단·보도 폭·문턱 데이터의 출처와 갱신, 현장 검증 및 API 이용약관 검토가 별도로 필요합니다.
