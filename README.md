# 턱없이 — 사천시 접근성 지도 MVP

휠체어 이용자가 경로의 경사와 OpenStreetMap 장애물 정보를 확인하도록 돕는 웹앱의 초기 버전입니다. 사천시청 좌표(35.0036, 128.0642)를 지도 중심으로 사용합니다.

## 실행

- Node.js 20.6 이상
- `npm install`
- `.env.example`을 `.env`로 복사하고 API 키 입력
- `npm start`
- `http://localhost:3000` 접속

`TMAP_APP_KEY`는 장소 검색과 경로 조회에 필요합니다. `NAVER_MAPS_KEY_ID`는 브라우저 지도 표시에 필요하며 네이버 콘솔에 로컬/운영 웹 서비스 URL을 등록해야 합니다. `NAVER_API_KEY_ID`와 `NAVER_API_KEY`는 네이버 자동차 Directions 사용 시 설정합니다. TAGO 키가 없으면 버스 기능은 안내 메시지를 표시합니다. 비밀 키가 포함된 `.env` 파일은 절대 커밋하지 마세요.

## 제공 기능 및 상태

- 장소 자동완성(300ms), 사천시청 근접 순 정렬, 지도 클릭으로 출발/도착 지정
- TMAP 보행자 옵션 30/10 병렬 조회, 자동차는 네이버 우선 후 TMAP 대체
- Open-Meteo 고도 샘플링(요청당 최대 100개), 경사 구간 지도 표시 및 추정 휠체어 시간
- Overpass 계단·높은 턱·wheelchair=no 표시 및 경로 주변 경고
- TAGO 주변 정류장 조회 기본 연동, 실시간 도착/저상버스 필드는 서비스 응답 항목에 따라 추가 검증 필요
- 현장 제보 입력. 현재 서버 메모리에만 저장되므로 재시작 시 사라짐

## 한계와 안전

고도 데이터는 약 90m 해상도이며 짧은 구간의 실제 경사를 보장하지 않습니다. OSM의 턱·폭·경사 태그와 보행 그래프는 지역별로 불완전합니다. TMAP의 계단 제외는 턱이나 좁은 보도를 걸러낸다는 보장이 없습니다. 외부 API 가용성·사용량 제한과 응답 스키마 변경이 있을 수 있습니다. 이 앱은 접근성 정보 참고용이며 이동 전 현장 확인이 필요합니다.

운영 전에는 제보 저장소를 SQLite/PostGIS로 교체하고, 사진을 별도 객체 저장소에 저장하며, TAGO 실시간 도착/저상 정보 응답, 인증·요청 제한, 개인정보 및 접근성 테스트를 추가하세요.
