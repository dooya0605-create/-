# 턱없이 — 마산 이동약자 접근성 길찾기 시제품

마산대학교 × ANCHOR 2026 해커톤 팀 프리웨이의 PRD/TRD를 바탕으로 만든 반응형 웹 시제품입니다. 마산 생활권 지도, 등록 장소 선택, 한정된 시연 경로 비교, 기기별 참고 시간, 장애물 상태 설명, 배터리 계산, 충전소·버스 정보 상태, 위치 권한 안내, 상담 입력 검증을 포함합니다.

## 바로 실행

### 브라우저에서 열기
`public/index.html`을 내려받아 브라우저에서 열 수 있습니다. 지도 타일과 Leaflet은 인터넷에서 불러오므로 네트워크 연결이 필요합니다. 위치 기능은 HTTPS 또는 `localhost`에서만 동작합니다.

### 로컬 서버에서 실행
Node.js 20 이상이 있으면 저장소 루트에서:

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`을 엽니다. 이 정적 시제품 화면에는 API 키나 `.env` 설정이 필요하지 않습니다.

## 배포

`public/index.html`은 정적 웹 파일이므로 GitHub Pages, Cloudflare Pages 또는 기타 정적 호스팅에 배포할 수 있습니다. GitHub Pages를 쓰려면 저장소 설정에서 Pages 배포 소스를 `main` 브랜치의 `/public` 폴더로 지정하거나, `public/index.html`을 배포 루트의 `index.html`로 복사해 사용하세요.

## 작동하는 화면 동작

- 반응형 웹 UI 및 OpenStreetMap 기반 실제 지도 확대·축소·이동
- 등록된 마산 장소 선택, 출발지/도착지 바꾸기, 지도 중심 이동
- 시범 데이터에 등록된 장소 쌍만 경로 후보를 표시하고, 등록되지 않은 쌍은 경로 확인 불가 안내
- 쉬운 길·빠른 길 샘플 경로 및 상태를 지도와 결과 카드에서 구분
- 수동휠체어·전동휠체어·전동스쿠터·유모차 선택에 따른 고정 속도 기준 시간 계산
- 배터리 잔량·완충 거리·환경계수를 사용한 시연용 거리 계산과 입력 경계 검증
- 충전소·버스 정보의 샘플/미연동 상태 안내
- 사용자가 직접 누를 때만 브라우저 위치 권한 요청, 거부/실패 상태 안내
- 이름·전화번호·상담 내용 입력 검증 및 제출 피드백

## 데이터·안전·개인정보 고지

지도 배경은 OpenStreetMap 기반이며 저작자 표시가 지도에 보입니다. PRD의 NAVER Maps SDK는 공개 ID와 허용 도메인 설정 및 API 약관 확인이 필요하므로, 키가 없는 현재 브라우저 시제품은 키 없이 사용 가능한 OSM 지도를 사용합니다.

경로선·거리·장애물 판정·장소 좌표·충전소 표시는 제한된 정적 시연 데이터입니다. 이는 현장 조사나 승인된 실제 마산 경로를 뜻하지 않으며 실제 이동에 사용하면 안 됩니다. 시연 데이터에는 출처·기준일·샘플 상태를 표시하고, 등록되지 않은 출발·도착 조합에 임의 경로를 만들어 내지 않습니다. 현재 버스 실시간 도착, 저상버스 탑승 가능 여부, 충전소 운영·충전 가능 여부, 실제 도로 경로 탐색은 연동되어 있지 않습니다.

현재 위치는 사용자 클릭 후 브라우저에서만 확인하며 서버로 전송하거나 저장하지 않습니다. 상담 폼은 입력 검증 및 성공 상태만 시연하고 이름·전화번호·상담 내용을 전송하거나 저장하지 않습니다. 실제 접수에는 백엔드 연결, 개인정보 처리방침과 동의가 필요합니다. 119는 사용자가 직접 전화 앱을 열어 연락하는 링크이며 자동 신고 기능이 아닙니다.

배터리 계산은 `완충 주행거리 × (잔량/100) × 환경계수 × 0.85`이며 환경계수와 0.85는 검증되지 않은 시연용 가정입니다. 예상 거리는 안전이나 목적지 도달을 보장하지 않습니다.

지도 데이터 이용 조건: [OpenStreetMap 저작권 및 기여자 안내](https://www.openstreetmap.org/copyright). 공공 타일 서버는 무제한 상업용 지도 API가 아니며, 정식 서비스에서는 타일 제공자의 사용 정책을 검토해야 합니다.
