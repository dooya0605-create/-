# 턱없이 — 마산합포구 접근성 길찾기 시연

가상 지도를 제거하고 실제 마산합포구 배경지도를 띄우는 **실행 가능한 웹 화면 프로토타입**입니다. 접근성 우선 경로, 최단 거리 경로, 급경사·계단·좁은 보도·문턱 회피라는 제품 콘셉트를 시연합니다.

## 가장 빠른 실행 방법

### 준비물

- Node.js 20.6 이상
- 인터넷 연결(지도와 MapLibre 라이브러리를 외부에서 불러옵니다)

### Windows PowerShell

```powershell
git clone https://github.com/dooya0605-create/-.git
cd -
npm install
npm start
```

### macOS / Linux

```bash
git clone https://github.com/dooya0605-create/-.git
cd -
npm install
npm start
```

터미널에 서버 주소가 표시되면 브라우저에서 [http://localhost:3000](http://localhost:3000)을 여세요. 종료할 때는 터미널에서 `Ctrl+C`를 누릅니다.

이 시연 화면은 지도 키나 `.env` 파일을 요구하지 않도록 실행 스크립트를 구성했습니다. `npm start`는 `server.js`에서 정적 웹 화면을 제공하며, 화면의 시연 동작에 TMAP·네이버·카카오 API 키가 필요하지 않습니다.

## 화면 조작

- 지도에서 마산합포구 배경을 확인합니다.
- `지도에서 출발지 선택` 또는 `지도에서 도착지 선택`을 누른 뒤 지도 위치를 클릭합니다.
- `접근성 경로 탐색 시연`을 눌러 추천 경로를 강조합니다.
- 경로 카드를 누르면 접근성 우선 예시와 최단 거리 예시의 강조 표시를 전환합니다.
- `마산합포구 보기` 버튼은 초기 지도 중심으로 돌아갑니다.
- 브라우저에서 화면 캡처를 하거나 인쇄 메뉴에서 PDF로 저장해 발표 자료로 사용할 수 있습니다.

## 이미지 캡처

- Windows: `Win + Shift + S`로 화면 영역을 캡처합니다.
- macOS: `Shift + Command + 4`로 영역을 캡처합니다.
- 전체 화면 또는 발표용 이미지가 필요하면 브라우저 창을 원하는 크기로 조정한 뒤 캡처하세요. 모바일 화면은 개발자 도구의 기기 미리보기에서 확인할 수 있습니다.

## 시연 범위와 주의사항

실제 마산합포구 지도 배경은 외부 타일 서비스에서 불러옵니다. 인터넷 연결이나 서비스 상태에 따라 지도가 일시적으로 표시되지 않을 수 있습니다.

경로 선, 출발·도착 기본 위치, 거리·시간, 경사 및 장애물 태그는 **기능 콘셉트를 설명하기 위한 예시**입니다. 출발지·도착지 텍스트를 실제 지오코딩하지 않고, 실제 도로망 경로를 계산하거나 접근성·안전성을 검증하지 않습니다. 이 프로토타입을 실제 길찾기나 이동 안전 판단에 사용하지 마세요.

실서비스에는 장소 검색, 보행 네트워크 경로 계산, 현장 검증된 경사·계단·보도 폭·문턱 데이터, 데이터 갱신 절차가 별도로 필요합니다.
